# 🏆 بطولات فيفا 26

منصة شاملة لإدارة بطولات فيفا مع قاعدة بيانات متقدمة

## ⚙️ إعداد قاعدة البيانات

### 🔧 ملف الإعدادات
جميع إعدادات قاعدة البيانات موجودة في:
```
config.js
```

### 📝 تحديث بيانات قاعدة البيانات:
1. افتح ملف `config.js`
2. حدث `SUPABASE_URL` برابط مشروعك
3. حدث `SUPABASE_ANON_KEY` بمفتاح API الخاص بك
4. احفظ الملف وحدث الصفحة

### 🗄️ إنشاء الجداول:
1. اذهب إلى Supabase Dashboard
2. SQL Editor
3. انسخ محتوى: `supabase/migrations/create_complete_tournament_system.sql`
4. شغل الكود

## 🧪 اختبار قاعدة البيانات
افتح: `http://localhost:5173/database-test.html`

## 🚀 تشغيل المشروع
```bash
npm run dev
```
